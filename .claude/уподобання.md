# Лог уподобань

Персональні вподобання власника репо щодо ведення цих нотаток.
Веду цей файл я (Claude) і оновлюю по ходу роботи.

## Мова і тон
- Українська, неформально. Сленг і гумор доречні («збс», «шляпа», «вкуснятина»).

## Формат нотаток
- Максимально стисло, «висушено». Орієнтир розміру — `мінімум-для-grpc-між-мікросервісами-на-azure.md`.
- **Жирним** — ключові терміни.
- Незнайомі терміни пояснювати коротко inline (ingress, Envoy, Dapr…).
- Кут — .NET/Azure специфіка, це суть проєкту.
- Часто присутній підсумок / «формулювання для співбесіди» (але інколи ріжеться — уточнювати).

## Процес
- Вільне обговорення → чернетка → сушимо → зберігаємо в корінь → **commit + push щоразу**.
- Файли — в корені, без підпапок (поки). Можливо, числовий префікс згодом.
- Назви файлів — українською, kebab-case, описові, ловлять суть/цінність. Фінальну назву часто обирає власник сам.

## Чого уникати
- Слів-ярликів типу «сініор» у самому тексті нотатки — зашквар як для інструкції.
- Наївної/маркетингової подачі без меж застосування.

## Що цінує
- Чесність: якщо теза перебільшена (напр. «ORM вимагає контролерів») — прямо це позначати.
- Показувати «де це НЕ підходить / оверкіл» — межу застосування.
- Запам'ятовувані метафори/сюжети (напр. ресторан для OpenAPI).
