# Ticketmaster — що нового (.NET/Azure)

Ядро те саме, що в подібних кейсах (read-heavy кеш + строга транзакція на бронь). Нове — оце:

## 1. Hold місця → Redis TTL
- місце тримають за юзером на 5–10 хв, поки платить; не встиг → **само звільнилось**;
- `SET seat:{id}=userId NX EX 600`: **`NX`** = distributed lock (взяв, лише якщо вільно), **`EX`** = авто-звільнення **без cron**;
- **база чіпається лише на оплаті** (durable «booked»); hold живе **тільки в Redis**.
- Azure: **Azure Cache for Redis**.

## 2. Ажіотаж (10M на подію) → кеш шарами
Читання осідають **шарами**: **CDN** (метадані події) → **Redis** (кластер + репліки) → апка за балансувальником. До бекенду доходить усе менше.

## 3. Черга очікування (буфер перед бронюванням)
Захищає крихке бронювання, перетворюючи сплеск на рівний потік:
- прийшов — дістав **позицію + токен** (кукі/підписаний рядок) = **твоє місце в черзі**; закрив вкладку → токен береже позицію;
- черга живе в **Redis** (list/ZSET, FIFO по приходу);
- **клапан** впускає дозовано: N/сек або «один вийшов — одного впустили»;
- впустили → видали **admission-токен** (підписаний, час-обмежений) → **лише з ним** пройдеш у бронювання;
- вхід дешевий (Redis + **статична сторінка очікування на CDN**), тож 10M не валять саму чергу.
- Azure: **Redis** (черга), **SignalR/SSE** (позиція), **Front Door/APIM** (ворота, rate limit).

## 4. Пошук → Azure AI Search
Повнотекстовий по полях події (назва/виконавець/місто/дата), **fuzzy** на одруки; синхрон із БД через **CDC/indexer**; масштаб — **репліки + партиції**. Не `LIKE`, не власний Elastic.

## 5. Жива мапа місць → SSE
Місця гаснуть наживо → **SSE** пушить оновлення. Стережись **буферизації/idle-таймаутів на краю** (вимкнути буфер, keep-alive) або бери **Azure SignalR** для масштабу. Для мега-подій живу мапу дають лише **впущеним** (черга гейтить фан-аут).

**Суть:** нове в Ticketmaster — **hold місця через Redis-TTL** (`NX`-лок + авто-звільнення, база лише на оплаті), **черга очікування** (токен = місце в черзі, admission-токен = дозвіл увійти, дозоване впускання), **Azure AI Search** замість `LIKE`, і **SSE/SignalR** для живої мапи. Кеш ловить читання шарами (CDN→Redis→апка).
